## 📌 About

This project is a straightforward **Employee Management System** developed as part of a **Build in Public** initiative. The goal is to build this system incrementally — starting from raw functional logic and evolving it into a clean, secure, production-ready application.

---

## ⚙️ How It Works

### Workflow

| Step | Description |
|------|-------------|
| **1. Data Entry** | Employee details (Name, Email, Position, etc.) are entered via a user interface. |
| **2. Processing** | Backend logic receives and validates the form data. |
| **3. Database Interaction** | CRUD operations are performed on the database. |

### CRUD Operations

- **Create** — Add a new employee record to the database.
- **Read** — Fetch and display all records in a tabular format.
- **Update** — Edit existing employee data and save changes.
- **Delete** — Remove a record when no longer needed.

---

## 🚧 Current Status

> **Phase: Pre-Logic (Functional Logic Only)**

This is a raw, early-stage implementation. The focus right now is purely on making CRUD operations work.

### Known Limitations

| Area | Current State |
|------|--------------|
| **Architecture** | No formal pattern (e.g., MVC) implemented yet. |
| **Security** | No Prepared Statements or advanced input validation. SQL Injection protection is pending. |
| **UI / UX** | Minimal design — functionality over form at this stage. |
| **Code Structure** | Monolithic; modularization not yet applied. |
